# すくう

> 流れる日々から、記憶をすくい、つづっていく。

## 1. プロダクト概要

### コンセプト
体調や活動、ケアなどの日々のアクションを拾い上げ、
自分を整え続けられる。

### 目的
- 日々の体調や活動、ケアを無理なく記録する
- 「できごと」と体調の変化を後から振り返れるようにする
- Googleカレンダーの予定を再入力せず、必要な予定だけを記録につなげる
- 長期的に、自分のコンディションや行動パターンを把握できるようにする

## 2. 設計方針
- 記録すること自体を目的にしない
- できるだけ入力負荷を増やさない
- 予定管理はGoogleカレンダー、振り返りは「すくう」と役割分担する
- 体調だけでなく、運動・ケア・活動・美容・医療も一つの流れで扱う
- カテゴリや項目は自由に追加・削除・名称変更できる
- UIは静かで情報量を抑え、毎日使いやすいことを優先する

## 4. 今日の記録
基本項目:
- 体温
- 体調点数（0〜10）
- 睡眠時間
- 症状
- メモ

「その他の記録」は折りたたみ表示。
初期項目:
- お通じ
- 体重
- 血圧
- その他

お通じ:
- なし
- 硬め
- 普通
- 軟らかめ
- 下痢

## 5. できごと
「イベント」ではなく「できごと」と呼ぶ。

保持する情報:
- カテゴリ
- 項目
- 日付
- 開始時刻
- 終了時刻
- 時間（分）
- status
- 事前メモ
- 実施メモ
- Googleカレンダー由来かどうか
- Google Calendar event ID
- Google Calendar event label ID

事前メモ: 実施前に残したいこと。
実施メモ: 実施後の内容・感想・結果。

## 8. Googleカレンダー連携

### 基本方針
専用カレンダーは必須としない。
Googleカレンダー上で「イベントラベル」が付いている予定だけ取得する。
ラベルのない予定は無視する。

### ラベル紐付け
初回のみ、Googleカレンダーのイベントラベルと「すくう」のカテゴリ・項目を対応付ける。

例:
- 「ピラティス」→ 運動 > ピラティス
- 「全身ケア」→ ケア > 全身ケア（インディバ等）
- 「つきあかり開発」→ 活動 > つきあかり開発

Googleカレンダーのタイトルは自由。
分類にはタイトルではなくイベントラベルを利用する。

### 役割分担
Googleカレンダー:
- 予定
- 時刻
- 場所
- 通知
- 共有

すくう:
- 体調
- 実際に行ったできごと
- 事前メモ
- 実施メモ
- 振り返り
- 分析

### ユーザーフロー
1. Googleカレンダーに予定を登録
2. 必要な予定にイベントラベルを付ける
3. すくうがラベル付き予定を取得
4. 今日の「できごと（予定）」として表示
5. 実施後に実施メモを追加
6. 体調記録と合わせて履歴に残る
7. 分析画面で体調との関係を振り返る

予定にない活動は、アプリ内から直接「できごと」として追加可能。
