# 日々抄 (nichinichi-sho)

> 流れる日々から、記憶をすくい、つづっていく。

## 概要

日々抄は、日々の体調・活動・ケア・出来事を記録し、振り返りを支援するライフログアプリです。

## 技術スタック

-   Next.js
-   TypeScript
-   Tailwind CSS
-   Supabase
-   PostgreSQL
-   Render

## セットアップ

``` bash
npm install
npm run dev
```
